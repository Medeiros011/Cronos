# Cronos

Controle financeiro pessoal (PWA) — lançamentos, parcelados, recorrentes, metas e análise.

- Tela de boas-vindas animada com o logo
- Lançamento de gastos por comando de voz (Chrome, pt-BR)

Os dados ficam salvos apenas no aparelho (localStorage). Use **Ajustes → Exportar JSON** para backup.
