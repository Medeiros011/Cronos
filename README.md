# Cronos

Controle financeiro pessoal (PWA) — lançamentos, parcelados, recorrentes, metas e análise.

**App:** https://medeiros011.github.io/cronos/

## Destaques da versão 2.0
- Tela de boas-vindas animada com o logo (o tempo desenha o "C", as moedas se empilham)
- Lançamento por voz em português ("45,90 no mercado", "farmácia 120 reais em 3 vezes")
- Comparação com o mês anterior e projeção de gasto do mês
- Últimos lançamentos na tela inicial e busca em todo o histórico
- Atalhos dos gastos mais frequentes no lançamento
- Remover com "Desfazer" e remoção de todas as parcelas de uma compra
- Gráfico dos últimos 6 meses
- Funciona sem internet (service worker) e lembrete de backup

Os dados ficam salvos apenas no aparelho. Use **Ajustes → Exportar JSON** para backup.
